# 🌤 Daily Weather Automation using n8n

A beginner-friendly automation built with n8n that retrieves daily weather data from the Open-Meteo API and sends or stores the results automatically.

## Features

- Schedule automation
- Fetch live weather data
- Parse JSON responses
- Send notifications or save to Google Sheets
- Beginner-friendly workflow

## Workflow

Schedule Trigger
↓
HTTP Request
↓
Edit Fields
↓
Google Sheets / Email

## Technologies

- n8n
- Open-Meteo API
- Google Sheets (optional)
- Gmail (optional)
